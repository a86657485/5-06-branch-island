## 三、不是缺陷、但课堂需知的行为

1. **控制柜的填写模型是「先点槽位，再点卡片」**，且当前槽位会自动前进（条件 → 是 → 否）。直接连点卡片会把卡放到当前高亮槽。
2. **填错会弹「手把手引导」对话框**，关闭按钮为「💡 我知道了，继续尝试」，关掉后可「🔄 重新选卡」，不会卡死。
3. **第一个温度需要填卡 + 拼句 + 预测三个温度**；第二个温度起，控制柜直接询问「现在直接启动风机检验吗？」，点「🚀 立即用 N℃ 启动实测」即可，不必重填。
4. **验收问答答对后，还要点「领取下一站委托」**，并等待约 2 秒同步，积分与「已完成」才落库（实测 +25 分、`valid=true`、`reason=boundary`）。
5. **重进是否重放剧情取决于本机记录**：同一浏览器不会重放；换设备或清缓存会重放一次且此时无跳过键（设计如此）。
6. **贴墙或贴柜体时可能短暂走不动**：换方向即可移动（实测左侧边界 x=640、右侧 x=904）。低年级学生若反复顶同一面墙，会误以为卡住，建议口头提示「换个方向绕一下」。
