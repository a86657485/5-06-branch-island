3. 实际加入“交谈/操作”按钮，远处禁用；只触发当前地图、当前active player、48px内最近可见对象。自动前往保留原真实移动和事件。面板、宿主浮层、错误提示与自动行走阻止手动输入，释放摇杆；旧地图/旧玩家的迟到提示或动作被拒绝。
4. 各站三幕现场委托，每幕两句：事件和人物需要→现场规则与问题→学生观察/测试任务。温室新装设备与备用控制板故障前后衔接；不以旁白虚构已经模拟的温度下降或植物恢复。教材变为按需巡检手册，可关/回看；旧已读教材标记不跳过新版背景。
5. 预测、控制柜和解释围绕风机、导行屏、充电柜与NPC需要提问。预测显示当前程序，返修故障不按理想规则伪报。核验直接对照实际动作、原预测与告示/现场约定，不加二次确认。理由id、所有规则及判据沿用。

## 性能数字的含义

同样19个引导点、静止60帧，旧实现创建1140个span；现在首帧初始化后节点增删、文字/样式和高亮变更均0，单帧画布rect读取最多1次。五次相同checkpoint原至少15次玩家同步、30次图像/名牌设置；现在重复演员同步与变量写入为0。相机/视口/目标变化仍跟随。这些是真实函数在VM中的调用计数，证明多余工作减少，不是华为真机FPS或整班并发数据。
