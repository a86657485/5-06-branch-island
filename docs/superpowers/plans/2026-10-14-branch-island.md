# 分支冒险岛实施与验收计划

目标：依据五年级第6课实际教材，完成可在课堂局域网使用的分支探究应用与教学设计，验证后上传 GitHub。

架构：Node 22 内置 HTTP 与 SQLite，四个主线任务共享可验证规则。原始教材、正式名单、学习数据库保留本地；公开仓库使用虚构示例名单。

## 教学与视觉设计

本课为编程思维课。核心理解是根据条件选择一条路径，以及反转条件时同步调整出口。推荐二维科技公园，售票/维修/路口/双数四站；流程图使用菱形判断、是/否箭头、平行四边形输入/输出、汇合与结束，执行高亮与实际规则一致。

视觉使用天空蓝 #E9F4FF、深海蓝 #153758、湖绿 #147D78、阳光黄 #FFCF5A、珊瑚 #F27D65、纸白 #FFFFFF。中文标题与正文用本机圆体/苹方，数据用等宽数字。特色为场景与可编辑流程图同屏，装饰不压过控件。比较像素RPG与3D方案后选择二维，以便观察分支与在普通机房流畅运行。

容量：推荐45分钟（登录导入3，四站26，20题检测12，收尾4）。40分钟备选保留至少25分钟探究，检测后半或订正续做。此为设计预估，课堂需校准。
