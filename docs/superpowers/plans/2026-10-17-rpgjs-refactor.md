# 第6课 RPGJS 场景重构

已授权范围：参考用户指定 rpgjs/starter，将现有四站教学活动装入真实RPGJS引擎，保留学生学习证据并更新GitHub。原应用保持可用，直到新版验证完成。

1. 固定上游与依赖，采用兼容的核心5.0.0组合。验证：来源、MIT许可、可构建。
2. 将自有生成图、人物帧和设备放入Tiled地图，建立移动/碰撞/原生事件。验证：运行时底图、角色、NPC、实体移动和安全通道。
3. 迁移温室/维修/道路/电池四站，模型评估复用已有规则。验证：预测先于输出、错误保留、修订后重新验证、边界与双分支覆盖。
4. 同源桥接沿用身份/同步/SQLite/教师图表，有限引擎位置用于恢复。验证：身份与任务归属、断网补传、重启/换设备与积分去重。
5. 类型及规则检查、独立审查、实际浏览器完成主线；构建产物随仓库发布。通过后再部署正式入口和推送GitHub。

不将移动速度、观看对白、理由句块或积分单独解释为理解。真实名单、数据库、教材全文与备份不发布。旧画布版保留为显式兼容入口。
