# RPGJS 浏览器检查记录

本文件记录 2026-10-17 在隔离工作树、临时课堂服务 `http://localhost:18769` 上的浏览器检查。正式课堂端口 8766 未用于本轮写入。浏览器为本机 Google Chrome，通过 Playwright 控制真实页面；所有课内操作均点击按钮、持续按住方向控件、走近并面向 NPC 或设备，不调用内部动作函数，不注入实验、积分或位置。

## 已实测通过

- RPGJS 公园底图、人物、场景物体显示；角色能够实际行走。
- 走近管理员开启原生事件对话；关闭按钮与 Escape 均可退出对话，关闭后角色能继续移动。
- 温室分别读取 29、30、31°C，设置判断条件的两个分支，先预测再执行，实际走到现场核验仪保存结果，向管理员解释边界值后获得 25 积分。
- 29°C 先预测“启动”，程序实际执行“关闭”。错误预测与实际输出分别保留，后续正确预测没有覆盖首次预测。
- 维修任务在尚未观察故障前锁定修改；实际执行原错误程序的 30°C，保存“关闭/目标启动”的错误运行。交换两个出口后重新核验 30、29、31°C，说明条件反向与出口交换的关系后获得另外 25 积分。
- 证据分别保留原错误配置、修后配置、输入、预测、条件真假、实际分支、输出与动作顺序。温室动作链为 `measure → predict → ticket → gate`，维修动作为 `inspect → predict → ticket → gate`。
- 漏核验时，完成检查会提示缺少该输入的实际测试，不发放积分。

## 当前发现及待复验

浏览器完整旅程到 50 积分后切换路口，发现跨地图后对话存在旧玩家对象的生命周期问题。刷新进入路口后能连续与巡检员交流；切换有桥/无桥地图后，提示对话的“返回现场”无法真正关闭，角色输入保持阻塞。开发正在修复，须重新从剧情跨图和设施跨图走完整旅程后才能声明通过。

路口两条完整实体路线、无桥错误、红灯安全门、两组电池、100 积分、20 题、刷新与局域网入口属于本轮待验收项目。当前尚未使用另一台实体学生设备。
