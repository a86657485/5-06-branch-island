# 华为擎云 C5e 平板适配记录

- 日期：2026-10-26
- 设备：华为擎云 C5e（Android 平板，10.95 英寸，物理 1920×1200，16:10）
- 应用：第 6 课《判断选择用分支》· 分支冒险岛（`a950938`）
- 测试方式：Playwright + Chrome，华为设备 UA（`Linux; Android 12; HUAWEI C5e`），触摸事件；**未在真机复核**

## 一、视口推算与测试档位

平板浏览器按 `物理像素 ÷ devicePixelRatio` 计算 CSS 视口：

| 假设 DPR | CSS 视口（横屏） | 说明 |
| --- | --- | --- |
| 2.0 | 960×600 | 保守档，浏览器工具栏后可用约 544 高 |
| 1.5 | 1280×800 | 乐观档 |
| 2.0（竖屏） | 600×960 | 旋转后 |

三档均实测，重点验证 960×600（最受限）。

## 三、本次修复

**问题**：竖屏（CSS 宽 600）时，顶栏四个按钮被压缩到 27–29px，低于可触控尺寸，学生容易点错。

**修复**：`public/style.css` 追加

```css
@media (pointer: coarse) and (max-width: 720px){
  .topbar.slim .identity button{min-height:40px;padding-top:6px;padding-bottom:6px}
}
```

修复后竖屏顶栏按钮 40px、站卡 44px，横屏不受影响（仍 61–63px）。

## 五、使用建议

1. **横屏使用**：960×600 下场景视野、控制柜面板与教师表格均正常；竖屏虽已可点，但场景偏窄。
2. 浏览器建议全屏（隐藏地址栏），可把可用高度从 544 提升到 600 左右。
3. 华为浏览器若默认开启「智能缩放/阅读模式」，请在设置中关闭，避免页面被二次缩放。
4. 真机首次使用建议先跑一遍 S1：确认触摸点击、长按方向键、控制柜卡片点选均正常（模拟器无法完全等价真机触摸）。

## 六、局限

本次为 UA + 触摸事件的模拟适配，未在真机验证以下项：华为浏览器的双击缩放、手势返回、输入法弹层、深色模式与护眼模式对配色的影响。建议课前用一台 C5e 实测 S1 一遍。
