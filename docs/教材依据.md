## 二、单元位置与目标来源

完整指南印刷页5（PDF第6页）的课程对应表，把第6课定位为“用流程图表示算法的分支结构、生活中存在的分支结构”，对应内容要求1、2、5。印刷页3（PDF第4页）的相关内容要求包括自然语言与流程图描述算法，以及认识顺序、分支、循环三种基本结构并分析简单执行过程。此处为本地教学指南的课标映射与内容呈现，本次没有另行声称已逐页核查独立课标原件。

第5课已经认识顺序结构及流程图；第6课增加菱形判断框与依据条件选择路径；第7课再认识重复操作与循环；第8课进入简单程序验证；第11课进一步涉及多分支。因此本版聚焦一个条件、两条路径、运行与修订，不要求学生掌握Python语法、循环或多分支组合。

本课印刷页35（拆分第1页、完整第36页）明确提出：借购票情境认识分支，初步用自然语言和流程图描述；分析规则以确定判断条件与执行路径。教学重难点对应判断条件、执行路径及分支流程图。这是四站与检测的直接目标来源。

门票对话中使用了“超过120厘米”的口语，而紧接着的规范表达明确采用“如果小于120，否则全价”。程序采用后者的完整规则，覆盖恰好120厘米，不制造边界空缺。教材门票规则是本课给定情境，不代表所有现实公园的现行售票政策。

双数任务依教材要求输入两个不同自然数，不把相等情况当作已经验证过的范围。`a＞b`方案虽然与示例写法不同，只要出口正确并通过两种大小关系的测试，应接受为等价方案。

## 四、逆向设计依据及本次转化

使用用户指定的 `play-learn-interactive-apps` 技能，并读取其逆向设计模块与“五种课型与35种策略”模块。方法用于先澄清目标，再确定证据与判据，最后安排体验与反馈；这些方法不冒称中国课标原文。

本课以编程思维为主。思维显影落实为与实际配置同步的流程图；对比调试落实为错误方案、运行结果、修订与重验。预制角色、提示、确定性规则和普通统计不标成学生正在使用实时生成式AI。

为减少打字与无关操作负担，采用控件、句块和自动记录；但避免只选对句块便判理解。四站把方案配置、关键输入、执行结果和理由放在一起，再以20题独立检测补充知识与新情境判断。首答、订正、最近和历史分开解释，重考高分不直接推断独立迁移。

用户的完整单课要求包括至少25分钟有效探究、至少20题考核。推荐45分钟安排为登录导入3、四站26、检测12、收尾4；40分钟备选保留探究，将未完成检测及订正延续到课后或下次。时长只是设计预估，不能用长剧情、强制等待或重复点击凑数。

## 五、20题与目标覆盖

题库为依据教材知识关系原创改写的四选一题，未复制教材全文；题目及解析位于应用根目录 `quiz.cjs`。

| 题号 | 覆盖内容 | 判断重点 |
| --- | --- | --- |
| q1—q3 | 分支概念、菱形框、单次执行路径 | 能区分判断选择与固定顺序或重复，知道是/否对应条件是否成立 |
| q4—q8 | 输入、门票条件、119/120/121及＜与≤ | 能识别必要数据，正确覆盖恰好相等的边界 |
| q9—q11 | 互补条件、是/否含义、出口修订 | 认识条件与出口的配合及等价规则 |
| q12—q14 | 测试不足、关键测试集、修改后重验 | 不以一个正确样例或旧通过状态代替完整验证 |
| q15—q16 | 有/无过街设施 | 依据条件选择完整且符合给定约束的行动 |
| q17—q18 | 双数推演与等价比较条件 | 识别较小数及相应变量输出 |
| q19—q20 | 新年龄规则、新电量规则 | 在新对象中按题目给定的＜或≤判断，不凭熟悉背景猜结果 |

20题正确选项位置0、1、2、3各5题；提交前不反馈正误，提交后提供答案、解析与回学。题目难度、解释可读性和误解诊断效度仍需课堂试做，不把选项分布均匀等同于测评有效。
