# 平板浏览器适配检查记录

- 检查日期：2026-10-22
- 检查对象：分支冒险岛（学生端、教师大屏、RPG 场景、控制柜、独立检测）
- 检查方式：Playwright + Chrome，模拟 iPad / 安卓平板，触摸事件（`touchscreen.tap`、CDP `Input.dispatchTouchEvent`）
- 测试数据：学生端使用隔离实例（临时数据目录），教师端使用「独立教师测试」，均不写正式课堂记录

## 四、发现并修复的问题

**问题**：短屏（可用高度 ≤ 760px，横屏平板含浏览器工具栏时的典型高度）下，控制柜面板底部「执行本次温度 / 返回现场」落到可视区之外；同时「×」关闭按钮被 `margin-left: calc(min(860px,100%) - 64px)` 推到面板右边缘之外，浮在地图上。

**修复**：在 `public/rpgjs/index.html` 末尾新增 `<style id="tablet-touch-fix">` 覆盖（不改动打包产物，不触发重新构建）：

- `.studio` 设为定位上下文，`.studio-close` 改为定位到面板右上角（`right/top: 8px`）；
- 高度 ≤ 760px 时，`.studio-actions` 变为 `position: sticky; bottom: 0`，底部操作条始终可见。

**修复后复测**：

| 场景 | 关闭按钮位置 | 底部操作条 |
| --- | --- | --- |
| 1024×768（可用 788×640） | 面板内（717–761 / 面板 16–772） | 559–613，在 640 内，无需滚动 |
| 768×1024（可用 532×778） | 面板内 | 707–751，在 778 内 |
| 桌面 1440×900 | 面板内（977–1021 / 面板 172–1032） | 正常，无回归 |

点「×」可正常关闭面板；`npm test` 仍为 125/125 通过。

## 五、使用建议

1. 平板优先横屏：场景更宽、HUD 不遮挡角色，控制柜面板一屏可容纳。
2. 竖屏可用，但场景呈竖长条，左右视野较窄，行走时略需频繁转向。
3. 学生机浏览器建议全屏（隐藏地址栏）以获得更大可用高度。
4. iPad Safari 若出现地址栏自动收起导致高度变化，本修复的 sticky 操作条会自适应，不需要重新加载。
