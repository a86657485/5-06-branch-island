# 平板行走与规则可读性调整（2026-10-26）

针对老师反馈的两点：**角色左右移动会卡**、**平板需要摇杆、规则字体要大和强调**。

## 一、角色左右移动“卡”的原因与修复

### 定位过程

查 `scripts/build-rpg-assets.cjs` 的 `packCharacter`：角色图集 `public/assets/characters.png` 对每个方向只提供**一张静态像**，打包时把同一张图复制成 3 帧，只有中间帧上下错开 2px：

```js
layers.push({input:image, top: row*fh + fh - height - 5 - (col===1?0:2)});
```

逐帧比对 `engineer.png`（216×416，72×104 一格）证实：

| 方向 | 帧0 与 帧2 | 帧0 与 帧1 |
| --- | --- | --- |
| 下（正面） | 不同（真实迈步） | 不同 |
| 左 | **完全相同** | 仅上下差 2px |
| 右 | **完全相同** | 仅上下差 2px |
| 上（背面） | **完全相同** | 仅上下差 2px |

引擎的 walk 动画按 0→1→2 播放（`Presets.RMSpritesheet(3,4)`，10 tick/帧 ≈ 166ms）。左右方向三帧里有两帧是同一张图，实际循环是 **A→B→A→A→B→A**，接缝处 A 连着出现两次，于是看起来像“走一下卡一下”。正面之所以正常，是因为它用了另一张真正的迈步图 `[1892,356,190,355]`。

### 修复方式

新增 `scripts/build-walk-frames.py`：保留第 1 帧（站立帧，引擎静止时也用它），用「下半身自髋线向下逐渐张开 + 前后摆动」合成第 0、2 帧的迈步姿态：

- 前腿张开 0.45、后腿 0.15，脚底处前后摆 3.5px，髋线处为 0（无接缝）
- 反查采样 + 预乘 alpha 双线性插值，不产生暗边
- 保持脚底基线与原有 2px 上浮节奏，尺寸仍为 216×416、72×104 一格

原始精灵表存档为 `scripts/assets/engineer.base.png`，脚本幂等：重复执行结果一致（实测三处文件 sha256 相同）。已在 `packCharacter` 上方加注释，提醒重新打包后必须再跑一次本脚本。

### 修复后

| 方向 | 帧0 | 帧1（站立） | 帧2 |
| --- | --- | --- | --- |
| 左 | 前腿领步、身体前倾 | 并步 | 后腿蹬地、身体后仰 |
| 右 | 同上镜像 | 并步 | 同上镜像 |
| 上 | 双腿对称张开 | 并步 | 双腿对称张开 |

实测：平板视口下用摇杆持续向左，连续 6 帧截图互不相同，截图中可见侧身迈步姿态（此前该姿态根本不存在）；`npm test` 225/225 通过。

## 二、平板摇杆

`public/rpgjs/index.html` 原本只有方向键样式、没有方向键元素，触屏上除了点地图没有持续行走的手段。

新增 `engine/public/joystick.js`（部署副本 `public/rpgjs/joystick.js`）：

- 引擎的行走入口 `engine.processInput` 在打包产物里不外露，键盘事件走的是同一通道，因此摇杆**派发 ArrowUp/Down/Left/Right 的 keydown/keyup**，与真实键盘完全同路径（已实测可驱动角色）。
- 只认指针方向：`pointer: coarse` 或（有触摸点且无精确指针）才显示；桌面 Chrome 虽然挂着 `ontouchstart`，现在也不会误显示。
- 死区 12px、最大位移 42px，四方向取主轴；松手回中并 keyup。
- 面板打开时（`.dialog-shade` / `.studio-shade` / `#engine-status`）不派发按键，另有 250ms 定时兜底松开，避免角色一直朝一个方向走。
- 位置：左下角 132px 圆盘，`#engine-feedback` 与 `#engine-assistance` 在触屏上抬到 160/170px，避免叠字。

实测（华为擎云 C5e UA，1024×768，DPR2，触摸事件）：摇杆 132×132、距底 16px、距左 14px；拖动 42px 后角色持续行走，画面连续变化；松手 `transform` 回到 `translate(0,0)`、`is-active` 移除；桌面（1280×800，鼠标）`display:none`。

## 三、规则字体放大与强调

在 `public/rpgjs/index.html` 末尾追加 `<style id="lesson-touch-ui">`，覆盖打包样式（scoped 属性选择器权重更高，故用 `!important`）：

| 元素 | 原 | 现 |
| --- | --- | --- |
| `.dialog-text`（规则句） | clamp(16,1.65vw,20) / 400 | clamp(18px,2.05vw,23px) / 600 |
| `.dialog-program`（条件与出口块） | 16px / 400 | 19px / 700，浅绿底 + 2px 深绿描边 |
| `.dialog-hint`（提示） | 15px / 400 | 17px / 600 |
| `.dialog-choices button` | 16px / 650 | 18px / 700 |
| `.studio-order`（控制柜说明） | 13px / 400 | 16px / 650 |
| `.studio-kicker` | 16px / 800 | 19px / 800 |
| `.studio-card / .flow-slot / .sentence-slot` | 16px / 400 | 17px / 700 |
| `#engine-task-hint`（任务提示） | 16px | 19px / 750 |

实测计算样式与截图见 `docs/screenshots/`：`rule-card-20261026.png`（教学卡）、`studio-rule-20261026.png`（控制柜）、`joystick-tablet-20261026.png`（摇杆位置）、`walk-left-20261026.png`（侧身迈步）、`sprite-sheet-20261026.png`（四向三帧总览）。

顺带把上一版升级时被覆盖掉的**控制柜关闭按钮定位**（`.studio-close` 固定面板内、短屏操作条 sticky）一起补回。
