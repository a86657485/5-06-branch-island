# 二维智慧园区场景验收

验收日期：2026年10月15日。最终结果：所列35条实际浏览器验收记录通过。这里的35条是场景操作、观察与验证记录，不是35个相互独立的单元测试，也不代表学生学习效果已测得。

场景是受深圳智慧园林启发的教学仿真；地图、人物及30℃试运行规则不代表某一真实园区的地理布局或控制规则。

## 测试环境与数据隔离

- Chrome实际页面；桌面1366×768、手机390×844。
- 独立测试服务 `localhost:18768`；仅示例名单 `roster.example.json` 与独立数据目录 `tmp/park-e2e`。
- 仅使用示例同学甲、乙和独立教师演示。未操作正式8766、真实名单或正式数据库。
- 主线通过实际UI点击、选择、键盘与鼠标操作推动，等待角色真正步行抵达后再交谈或操作。未调用程序内部函数、改写学习状态、直接请求通关接口或跳过行走过程。
- 只读页面已保存草稿与汇总接口用于核对数据。题库版本冲突通过一次陈旧 `/api/quiz` 响应模拟；随后由实际UI作答、实际服务端返回409和实际队列归档处理完成。
- 初轮标签重叠时仅点击标签外露的真实可点击区域继续主线，未使用force或事件派发绕过。最终修复后，对温室、交通和配电密集设备补测了中心真实点击及手机走查。

## 重点结果

| 目标或行为 | 实际观察 | 对应证据 |
|---|---|---|
| 判断条件有确定含义与边界 | 实读29、30、31℃，预测后执行风机再监测；30℃错误停机可观察并修订 | 各输入、条件成立与否、出口、实际设备结果与首次预测 |
| 改判断方向需调整出口 | 原故障先用30℃执行并监测；未重现故障时出口锁定，之后交换出口重测 | 原错误与修订后29/30/31℃记录均保留 |
| 一次执行对应的一条分支 | 有桥实际走天桥；无桥错误指桥留安全侧；红灯停在斑马线入口，绿灯才可步行到岸 | 正确路径、blocked错误记录、到岸核验 |
| 比较两个输入选择较小数 | 分别到A/B采集台，再到分配器预测；实际到选中出口取样、到充电口核验 | A3/B8与A9/B2两种大小关系；只一组即使解释正确也不加分 |
| 保存与隔离 | 刷新保留位置、输入、规则、运行记录；甲乙0/100分隔离；演示不进入测试班 | 本机草稿、服务端状态与教师汇总一致 |
| 提交后反馈与修订 | 20题漏答不可提交；提交前无正误；首次95、重做100、两次历史保留 | 首次、最近、历史与错题解析分开呈现 |
| 版本冲突不堵塞后续学习 | 陈旧版本20题提交409后完整归档未评分答卷，自动取新版，后续保存继续 | 完整20个答案、版本、原因、归档时间；未伪造新的检测成绩 |

## 完整浏览器记录

1. 虚构身份报到，学生只见园区与任务，教师入口未出现在学生页面。
2. 点击NPC后人物实际步行抵达才弹对话；首次对话可随时关闭，委托阶段保存。
3. 未经读取、预测、执行便核验被阻止，无实验无积分。
4. 30℃错误停机实际执行后才产生可见错误证据，提示修订出口。
5. 修订后实读29/30/31℃，分别执行与监测，解释边界后获得25积分。
6. 帮助立即关闭不清进度；刷新恢复规则、现场位置、4次实验与积分。
7. 维修必须先亲自读取30℃执行原错误，初始出口锁定，错误监测后才可修。
8. 维修交换出口再重验三温度，保留故障与修订证据，50积分。
9. 安全通行不能点击核验瞬移到对岸。
10. 东门有桥：预测后步行经天桥到对岸，核验留下路径证据。
11. 西门无桥错误指向天桥：角色留安全侧，blocked错误证据可回查。
12. 斑马线红灯阻止过街且不产生成功实验。
13. 绿灯步行经斑马线到对岸；到岸刷新后仍能核验。
14. 交通修订后重验有桥与无桥，两现场与唯一分支解释通过75积分。
15. 重启服务与刷新后保留携带A电池状态，中心点击充电口完成首组核验。
16. 只有一组大小关系，解释正确仍不能验收或加分。
17. 第二样本A9/B2实际到B出口取样充电，解释比较后100积分。
18. 20题缺答阻止提交，答题过程无正误提示，提交95分与错题解析。
19. 重做保留首次95、最近100与两次历史检测。
20. 教师大屏汇总100积分、首次与最近检测，展开可见场景顺序、输入、输出及修订。
21. 教师独立演示可跳关，对话不进入测试班数据。
22. 主线浏览器无pageerror异常。
23. 风机执行on后重新读取输入清除未核验结果，但设备保持最后实际执行on。
24. 修改预测不会自动停机或伪造新执行结果；服务器重启后保存字段与刷新一致。
25. 断网当页读取29℃与草稿待同步，恢复网络补传后刷新继续且不额外产生实验。
26. 人物真实行走中停下，刷新恢复停步坐标与草稿，不自动弹回对话。
27. 搜索姓名、切换示例乙与甲，0/100积分及学习记录隔离并恢复。
28. 交通最新布局安全员中心点击可步行抵达。

30. 定点修复复验与手机浏览器无pageerror异常。

32. 模拟陈旧题库响应：旧版20题提交409后完整归档未评分答卷、解除活动队列，自动重载新版，后续学习保存不阻塞。
33. 末轮边缘流程无pageerror异常。

## 首轮发现与修复复验

1. 温室养护员标签与控制柜重叠，中心点击被控制柜拦截；手机标签集中。后续分散设备点位并按实际屏幕矩形避让，最终温室NPC、探头、控制柜中心点击及手机操作通过。
2. 第一版标签避让只向上移动，配电充电口标签被推出舞台上边界。后续增加舞台边界约束、HUD避让及上下左右候选，桌面充电口中心点击、手机A/B采样—分配—取样—核验通过。
3. 风机状态新增独立的最后实际执行输出。实测on执行后，重读输入、改预测与刷新均不再无指令改变风机；同时未核验ticket按要求清除。
4. 到岸附近停下并刷新后，实际一次点击对岸核验即可完成，不需要再次点击。

## 实际边界

- 断网支持已经打开页面中的待同步记录保留与恢复补传；未配置离线整页缓存。网络断开时直接刷新页面，Chrome可能显示无法连接，恢复网络后再打开。
- 场景摘要与规则模型经过核对；它不是服务端逐帧重建人物移动。评估理解仍应结合首答、错误修订、口头解释与迁移任务，不能仅凭积分或句块理由认定掌握。
- 未进行实体学生机、整班并发、真实课堂时长与学生学习效果施测。
- 本轮浏览器和18768测试服务已关闭，测试数据仅保留在忽略的tmp目录；未停止正式服务或其他验收服务。
