## 实际浏览器验证

使用隔离端口18825、示例名单和教师独立演示，未使用正式学生身份。

1. 首次知识卡出现教材局部图、出处与任务目的；立即关闭，正常走向NPC。控制柜选好条件后重看知识，关闭后保留第2步和已选条件。
2. 普通四个条件候选均无答案描框；确认程序时主动用法宝，给确认按钮及原因，剩余5→4；关闭后换步骤不留原高亮。
3. 角色真实到探头采30℃，执行并走到核验仪。分别以 `≥ / 是关闭`、`> / 否关闭`、`≤ / 是关闭` 三个错误方案重复检验同一边界输入，依次出现观察、关键比较、局部示范；全程仍剩4次法宝。第二次后刷新，记录及额度保留；换返修站仍剩4次。
4. 示例身份通过真实API构造可验证的三站完成夹具，储能未做；正常登录直接进入基础11题。此项检验入口与门禁集成，不冒称该身份完成了浏览器行走。教师页对这份夹具显示3次免费帮助、最高第3级；预置返修故障未计入免费错误次数。

5. 返修站实际到探头采30℃，预测对白只保留简短问题，信息条同屏呈现旧程序 `≥ / 是关闭 / 否启动`。先学卡分别在1024×768、1920×1080检查，内容、退出与继续按钮均可见，临时视口已恢复。1024×768基础检测可滚动到其余内容。
