## 实际浏览器学习流程

| 验收项目 | 实际检查及结果 |
| --- | --- |
| 身份与保存 | 先选班级、再选虚构姓名进入；选择一个出口并等待“已同步保存”，再选另一出口并等待保存；两次改动均保留，刷新恢复正确。 |
| 售票站 | 故意设置错误出口，以120厘米运行，显示实际结果与目标差异；修改后测试119、120、121厘米，选择解释后通过，获得25积分。 |
| 售票等价方案 | `＜120`与`≥120`配合相应出口均通过；重验后积分不重复增加。 |
| 维修站 | 未观察原程序先检查完成受到阻止；以原错误规则运行120厘米，留下错误证据；交换出口后重新测试119、120、121厘米并解释，通过后累计50积分。 |
| 路口站 | “有设施”和“没有设施”分别运行，两条出口与单分支解释通过，累计75积分。 |
| 双数能量站 | 只测试一侧大小关系时不能通过；补齐a较小和b较小后通过；`a＜b`与`a＞b`的对应等价方案均接受，累计100积分。 |
| 修改后的重新验证 | 已通过规则改错后再改回，旧实验不能直接恢复当前通过状态；服务器当前验证为未通过，新实验完成后才恢复已验证，历史积分保留。 |
| 操作帮助 | 重看帮助可立即点击关闭，不清空当前输入、规则或已完成进度；手机上关闭按钮可见。 |
| 完成后的下一步 | 当前版售票站在任务标题旁显示“前往下一站”；同步流程图保留输入、判断、是／否输出、汇合结束。 |

## 20题检测与回学

- 未作答时提交受到阻止，并指出未答题目。
- 逐题作答和来回检查过程中不显示正误；20题全部作答后可提交。
- 故意答错1题后，反馈显示95分、错题答案及解释；可回到主线重新实验。
- 再次完成20题后最近成绩100分，首次95分和历史两次记录保留；刷新后仍可查看。
- 离线补交又形成第3次检测记录，首次与最近口径继续正确，刷新未产生第4次重复提交。
- 教师独立演示可查20题标准答案与解析，并实际完成20题检测得到100分。

## 同步、恢复与多客户端

| 验收项目 | 实际检查及结果 |
| --- | --- |
| 服务器重启 | 实际停止并重新启动测试服务，再开浏览器恢复已同步的四关、100积分和原有两次检测历史。 |
| 断网实验与通关 | 使用浏览器离线模式，在已打开的页面完成3次运行和一次关卡完成；本地显示25积分并保留待同步事件。 |
| 刷新后的待同步记录 | 阻断API并允许页面静态资源加载，刷新重进仍恢复本地完成状态；完成事件仍只有1条。恢复API后自动补传，服务器只有3次运行、25积分，之后刷新不重复。 |
| 离线检测防重复 | 离线提交20题后仅形成1条检测事件；API断连时刷新及离开再进入检测，答案、题号导航、提交按钮均冻结；恢复连接后只新增一次历史。 |
| 身份隔离 | 两个独立浏览器上下文分别登录虚构甲、乙；同设备切换后，甲的100积分与等价售票规则、乙的25积分与原售票规则分别恢复，没有串号。 |
| LAN非安全上下文 | 实际通过LAN IP的HTTP页面确认 `isSecureContext=false` 且 `crypto.randomUUID` 不可用；备用事件标识仍生成并成功同步一次实验。 |

断网检查包含已加载页面的浏览器离线操作；刷新恢复检查采用“阻断API、允许静态页面资源加载”的方式，验证本地状态和队列恢复。没有据此宣称完全断网时能够重新下载并首次打开页面。网络中断时应保留已打开的学习页面，恢复连接后自动补传。
